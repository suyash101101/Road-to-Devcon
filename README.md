## kohaku-railgun setup

```bash
git clone https://github.com/vg239/kohaku-railgun.git
cd kohaku-railgun
npm install
npm run setup
npm run demo:dry
npm test
```

## Develop the deck

```bash
npm install
npm run dev
```

Controls: `→` / `Space` next · `←` prev · `N` notes · `F` fullscreen

```bash
npm run build
npm run preview
```

Workshop lab copies live under `workshops/`.
